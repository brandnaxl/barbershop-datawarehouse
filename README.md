# Barbershop Data Warehouse Project

This is a full-stack data warehouse project built during my university semester. 
The project simulates a barbershop business case and demonstrates how to create an end-to-end DW pipeline from OLTP to OLAP and visualization.

## Objective
To provide business insight using OLAP techniques and support decision-making in a small retail barbershop scenario.

## Stack
- Microsoft SQL Server
- SSMS
- Visual Studio (SSIS)
- Excel Pivot Table
- SQL

## Workflow
1. **OLTP Database**: Modeled customer, service, and transaction data.
2. **ETL Pipeline**: Built using SQL and SSIS to move data to OLAP.
3. **OLAP Schema**: Star schema with fact and dimension tables.
4. **Pivot Report**: Customer behavior and sales insights.

## Files
- `/sql`: SQL scripts to create and load data.
- `/bak`: Backup files of OLTP & OLAP databases.
- `/docs`: Reports and analysis.
- `/pivot`: Final output from data visualization.
